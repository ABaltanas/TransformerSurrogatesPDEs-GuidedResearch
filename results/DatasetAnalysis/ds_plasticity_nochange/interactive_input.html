💡 What is this Input Parameter?

  • What it is: The raw 2D input tensor has shape (987, 101). Each row contains 101 height points describing the physical shape of a rigid die S_d(x) across the top width of the metal workpiece.
  • How it was generated: In the Geo-FNO study, the authors randomly selected 8 control points across the 50 mm span and connected them with piecewise cubic Hermite splines.
  • Why is it the only input? All material properties (Young's modulus E = 200 GPa, yield strength = 70 MPa), block dimensions (50 mm x 15 mm), and die speed (v = 3 m/s) are completely constant. The neural surrogate's goal is to learn the Geometry-to-Deformation Operator: mapping this die contour directly to the resulting 20-step internal plastic deformation.

⚙️ Underlying Simulation & Physical Parameters Source: Geo-FNO Paper (Not in .mat)

Important Provenance Note: These constitutive parameters and simulation boundary conditions are defined in the original benchmark paper ("Fourier Neural Operator with Learned Deformations for PDEs on General Geometries", Li et al., NeurIPS 2022 / JMLR 2023, arXiv:2207.05209). They are not stored as header metadata inside the raw plas_N987_T20.mat file itself (the .mat file stores only the resulting numerical tensors input and output).
